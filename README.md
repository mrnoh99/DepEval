# 우울 평가 (DepEval)

우울 증상을 **매일 척도**와 **주 1회 척도** 두 부분으로 나누어 기록하고, 변화를 표와 그래프로 확인하는 웹 앱입니다. 화면 구성과 사용 방식은 [PainEvaluation](https://github.com/mrnoh99/PainEvaluation)의 웹 앱을 그대로 따릅니다. 외부 라이브러리나 빌드 과정 없이 순수 HTML/CSS/JavaScript로 작성되어 있습니다.

## 구성 (3개 탭)

### 1. 매일 기분 체크 — 매일 기분 모니터링 체크리스트
- 문항 2개(각 0~3점: 전혀 없음 / 약간 / 상당히 / 매우 심함)
  1. 기분이 가라앉거나, 우울하거나, 희망이 없다고 느꼈다.
  2. 평소 하던 일에 대한 흥미나 즐거움이 거의 없었다.
- **PHQ-2 오늘의 점수** = 1+2번 합산 (**/6**)
- **전반적인 기분 점수** 1(최악)~10(최상)
- **수면 시간**(시간) 및 **질**(만족 / 보통 / 불만족)
- **기분에 영향을 준 특별한 사건** 한 줄 요약
- 하루에 한 건: 같은 날짜로 다시 저장하면 확인 후 덮어씁니다.

### 2. 주간 PHQ-9 — 주 1회
- 표준 PHQ-9 9문항(각 0~3점, "지난 2주일" 기준), 총점 **/27**
- 해석: 0–4 우울 아님 · 5–9 가벼운 · 10–14 중간 정도 · 15–19 약간 심한 · 20–27 심한 우울
- 9번 문항(자살·자해 생각)에 1점 이상이면 도움 요청 안내(자살예방상담전화 109)를 표시합니다.

### 3. 결과 분석
- **그래프**: 이중 축 선 그래프 — 왼쪽 축(0~10) PHQ-2·기분 점수, 오른쪽 축(0~27) PHQ-9
  - 범례의 체크박스로 계열을 켜고 끌 수 있습니다.
  - 한 손가락 드래그로 좌우 이동, 두 손가락 핀치로 간격 조절, ＋ / − / 기본 버튼
  - 기본으로 한 화면에 세로 7개 / 넓은 화면(600px 이상) 14개 표시
- **통합 표**: 날짜별 PHQ-2, 기분 점수, 수면 시간, PHQ-9

## 데이터
- 기록은 브라우저의 `localStorage`에만 저장됩니다(서버 전송 없음).
- **JSON 백업 / 복원**: 복원은 현재 기록에 병합하며, 이미 기록이 있는 날짜는 건너뜁니다.
- **CSV 저장 / 메일**: 날짜 기준으로 합친 CSV(Excel용 BOM 포함). 모바일에서는 공유 시트로 메일에 첨부합니다.

## 실행
- **로컬**: `web/index.html`을 브라우저에서 엽니다.
- **GitHub Pages**: `.github/workflows/deploy-pages.yml`이 `web/` 폴더를 배포합니다.
  최초 1회 저장소 **Settings → Pages → Source**를 **GitHub Actions**로 지정해야 하며, 이후 `https://mrnoh99.github.io/DepEval/`에서 접속합니다.
- **PWA**: 홈 화면에 추가해 앱처럼 설치하고 오프라인에서도 사용할 수 있습니다.

## 파일
```
web/
├── index.html            # 3개 탭 화면 구조
├── styles.css            # 스타일 (라이트/다크 자동)
├── app.js                # 문항, 저장, 그래프, 내보내기/가져오기
├── manifest.webmanifest  # PWA 매니페스트
├── sw.js                 # 서비스워커 (네트워크 우선 + 오프라인 캐시)
└── icons/
```

문항을 바꾸려면 `web/app.js` 상단의 `DAILY_QUESTIONS`, `PHQ9_QUESTIONS`를 수정하면 됩니다.

> 이 앱은 자가 기록 도구이며 진단을 대신하지 않습니다.
